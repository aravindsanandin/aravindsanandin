### ☁️ AWS Data Reliability Pipeline
> Production-style AWS pipeline that cleans, validates, and transforms messy raw data before it reaches analytics.

**Full Pipeline:**
```
S3 Bronze → AWS Glue ETL → Data Validation → S3 Silver → Gold Aggregation → Amazon Athena
```

**Key Features:**
- Schema enforcement + duplicate removal
- Date standardization + null detection
- Revenue validation + error quarantine
- Glue Data Catalog + Athena SQL queries
